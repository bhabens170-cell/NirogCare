## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Modern web browser

### Installation
```bash
git clone https://github.com/nirogcare/nirogcare.git
cd nirogcare
npm install
cp .env.example .env
# Add your API keys to .env
npm run dev
```

### Configuration
1. Get your Google Gemini API key from [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Add it to your `.env` file
3. Optionally configure Supabase for backend features
